# 让助手帮你操作手机

[English](phone-assistant.md) | 简体中文

**在手机桌面唤起助手，直接说「帮我打开高德地图搜索附近的公园」。** 助手根据整句选择搜地点，不会因此开始导航。未开启自动托管时，在卡片上点选地图；如果指定的地图没装，可以选另一款地图，也可以取消。

再次唤起会接着这个工作区上一次的「手机助手」会话。点「在应用中继续」会在完整应用里打开同一段聊天。要另起一段，点「新问题」，或说「刷新会话」「重开新会话」。

手机助手跨工作区共保留最近打开或更新的 10 段会话；超出的旧会话自动删除，正在执行的会话等任务结束后再整理。普通聊天和 Code 会话不受影响。一段会话可以有很多条消息：达到上下文压缩阈值后，助手用摘要继续。上次的手机操作授权不会随历史恢复。

## 让助手连续办完一件事

直接说你想知道什么或办成什么，不必列步骤。问「今天天气怎么样」，助手会考虑此刻的情况和接下来值得留意的变化；如果只想知道一个数，可以说「只告诉我现在几度」。办事时也一样：「打开应用签到」以看到签到结果为准。碰到不影响签到的待办，助手不会停下来让你处理；确实值得你留意的，再随结果简要说明。

问「现在几点了？」，助手会按提问时的设备时间报时。它可以用钟面辅助读数；只想看数字，就说「只告诉我时间」。

比较数据也不用先选图。比如问「周一到周三分别用了 12、9、6 分钟，整体变快了吗？」，助手可以用折线图说明趋势；点图上的一天查看具体耗时。想并排核对每个数时，也可以直接要求表格。手机操作是否完成，则看任务卡里的回执。

在快捷助手里直接说「开计算器计算 20 × 18」。默认会先出现任务卡：点「本次托管并开始」，助手就能自己打开计算器、按键、核对结果；点「允许并开始」，则沿用普通工具的审批设置。单问「20 × 18 等于多少」只是在聊天，不会操作手机。

**「自动托管」只改变审批。** 不管开关是否打开，你都可以直接说要做什么，让助手自己选工具。默认先请你批准；打开 **设置 → 跨应用助手 → 操作手机 → 自动托管手机任务** 后，切应用、点击、输入、发送和删除不再逐项询问。运行命令或脚本仍需确认。想接管时，再次唤起助手即可。

比如在群聊里问「他们在说什么东西？」不用特意说「自动化分析」。当前屏幕没露出名称时，助手可以翻前文、点开引用或查看大图；知道依据在哪里再回答。这里的「他们」指这次唤起时眼前的人。想讨论旧图就说「刚才那张图」；想让它不翻页就说「只看这张截图」。

查日程、目录或搜索结果也一样：告诉助手你要找什么，不用告诉它点哪一行。遇到几个同名条目，它可以把每行的标题、时间和地点放在一起判断，点进相符的条目读回答案。托管期间，如果不确定该点哪里，助手应重新看页面，而不是让你批准一次猜测。行边上的收藏、购买或发送按钮是另外的操作。

如果你指定要点桌面图标，助手会在系统桌面找匹配的图标，确认进入目标应用后才接着做。没有找到或页面不对时会停下来，不把打开首页当作完成整件事。

不用把任务拆成几条消息。托管时，助手能把同一页上可见的按键或填写步骤排成一组，例如一次安排计算器的六个按键；每一步都会重新核对控件。翻到另一页后，再根据新页面安排下一组。中间停下会记录哪些步骤已执行，不会从头重按。

如果助手在当前任务里问“是 9 × 19 吗？”，回答“对”或直接说出正确算式即可，不用重新唤起或授权。托管任务可以切应用，也能切回原来的页面。锁屏、取消或五分钟未回答后，本次控制结束。

**收起聊天，不等于停止任务。** 打开「在后台运行」后，发出请求就可以关闭面板或按返回。助手会接着做，不必重新提问。再次唤起可查看同一段对话；若有待批准的操作，仍然会等你决定。没有开启后台运行时，可回到应用内的原对话继续。

开启「Harness 手机操作」后，可以从屏幕顶部的小胶囊看进度或停止任务；没有启用内置无障碍服务时，看运行通知。任务结束会停在目标页面。已核实的结果显示「已完成」；需要接手或没有做完会另行标明。

## 助手怎么选操作方式

- **执行应用支持的指令**时，优先考虑公开接口，例如搜地点、设闹钟或打开笔记编辑页。打开编辑页不等于保存；设闹钟则可能直接创建闹钟。
- **查看这个页面能做什么**时，助手可以查询 Direct Actions（Android 10 及以上）。你也可以点「查看本页动作」在本机看列表，不会启动任务。同一个应用的不同页面可能提供不同动作。
- **要找控件、读原文或看图**时，助手可以直接看当前页面，不必先查一遍不相关的接口。它可以读控件、滚动、点开原图，或用本机文字识别。只有模型实际收到当前截图，才能按图上的坐标点击；系统禁止截图时不会绕过。

例如，时钟首页可能没有列出可直接执行的动作，但应用仍可能支持 Android 的公开闹钟和计时器接口。助手查询的是眼前这一页提供的动作，不是整款应用的功能清单。

## 第一次设置

在 AndroidHarness 里选一个能调用工具的聊天模型。无论是否开启自动托管，助手都把你的原话交给同一会话里的模型，判断你是想打开应用、进入里面某个页面，还是只想问个问题。开启自动托管后，模型可以直接选用手机提供的动作继续办事；关闭时由你点卡片开始。需要看图时，选支持图片输入的模型。

1. 在 AndroidHarness 的「设置 → 跨应用助手」中，将它设为系统默认数字助理。允许系统向助手提供屏幕上的文字；这样它才能识别你要操作的应用。按需开启侧边白线，或沿用手机原来的助理手势。
2. 公开接口和页面动作不需要无障碍权限。若还希望助手在没有接口时能点击或输入，在同页「操作手机」打开 Android 无障碍设置，启用「Harness 手机操作」。
3. 按助手提示开启后台运行；这样操作时面板可以让出屏幕。回到目标应用再唤起助手，而不是在 Harness 设置页里让它操作。
4. **想停止时，点任务胶囊或运行通知里的「停止」。** 只想看一眼进度，可以再次唤起面板，不用重开任务。操作期间侧边白线会暂时收起，不挡住目标页面。普通聊天不需要上述权限。

向内拉白线打开面板，上下拖动白线可以挪到顺手的位置。手机要求你验证身份时，直接在系统界面完成。屏幕文字和图片可能发送给你选择的模型。

## 从 Code 发起任务

在本地 Code 会话里发送 `/phone 在正文填入：明天九点开会，不要发送`。然后在十分钟内打开目标应用，唤起助手并选「操作手机」。你会看到来自 Code 的草稿，可以修改；只有点击「允许并开始」才会授权操作。

回到原 Code 会话发送 `/phone --result`，可打开最近一次已确认的手机会话，查看结果或停止的位置。发送 `/phone --cancel` 可撤回尚未确认的草稿；新草稿会替换旧草稿。只发 `/phone` 会打开助手设置。

## 把 AutoJs6 加为可选工具

内置服务不需要额外安装。需要 AutoJs6 的控件或脚本时，可以同时启用，不用关掉内置服务。

同一次任务可以更换手段：先检查 AutoJs6 是否连通，再用选中的服务重新看一眼界面。内置服务支持按住对象、移动、再松手的拖拽；AutoJs6 插件只声明滑动时，助手不会把滑动当成拖拽。已经发出但未确认结果的操作不会因为换了服务就重做。

1. 安装官方 [AutoJs6 6.8.0](https://github.com/SuperMonster003/AutoJs6/releases/tag/v6.8.0) 和 [MCP Server 1.3.1](https://github.com/SuperMonster003/AutoJs6-Plugin-MCP-Server/releases/tag/v1.3.1)。在 AutoJs6 中启动插件，允许插件发送配对通知，复制它显示的令牌。
2. 回到 Harness 的「设置 → 跨应用助手 → 操作手机 → AutoJs6」，填入插件显示的端口和令牌。令牌保存在本机的加密存储里。
3. 点「配对 / 检查连接」，在插件通知里确认配对。看到连接成功后，再回到要操作的应用唤起助手。

**哪些权限要开？** 让 AutoJs6 找按钮、点击、滑动和填字，打开它的「无障碍服务」即可；MCP Server 的「发送通知」用来显示配对请求和运行状态。语音输入用的是 AndroidHarness 的麦克风。只有配置了通知类提醒，才需要给 AndroidHarness 开「通知使用权」。这些操作都不需要给 AutoJs6 开悬浮窗、所有文件访问、Root、Shizuku 或局域网连接。

另外，**权限与插件的工具开关是两回事**：内置服务已经能滑动和拖拽。如果还想让 AutoJs6 执行坐标滑动，在 MCP Server 设置里开启手势工具组（`ui_gesture`，1.3.1 默认关闭）。截图默认走无障碍；只有回退到系统录屏时，才按当次任务需要确认屏幕共享。

**小米手机切到别的应用就断连？** 长按 **MCP Server** 的应用图标（或在系统应用管理中找到它），进入「应用信息 → 电量消耗 → 省电策略」，选择「无限制」，再回 Harness 检查连接。如果只在闲置一段时间后断开，检查插件是否启用了「空闲时自动停止」。手机重启后先打开一次 AutoJs6；如果之前手动关了服务，在 AutoJs6 侧栏重新开启「MCP 服务器」。不需要重新配对。

启用后进入脚本库，可保存并启用常用步骤，也可直接试运行一段不保存的脚本。「检查」在本地校验语句和步骤，不会触屏；实际运行在你授权的目标应用执行。例如，要检查表单已有“完成”按钮，再填写备注：

```js
text("完成").waitFor();
id("note").findOne(1500).setText("明天九点开会");
```

脚本支持按文字（`text`）、无障碍描述（`desc`）和控件 ID（`id`）定位，每行一个步骤。它不是通用 JavaScript 终端，不能借脚本执行 Shell 或访问文件、网络。关闭 AutoJs6 后，脚本保留，模型不再收到相关工具或使用提示。

要复用流程，可以说「用 AutoJs6 把这个表单的填法存成脚本，检查后在本页运行，停在核对页」。临时操作则说「用匿名脚本，不保存」。聊天中的「已使用 AutoJs6 脚本库」可能只是保存或静态检查；「已运行 AutoJs6 脚本」才是执行回执。脚本开头等到按钮出现，只能说明可以开始；要验证结果，把检查放在最后一次操作之后，读回目标应用显示的值。

## 慢慢说，停顿不等于说完

要慢慢说一段普通话，在语音设置里把「听写」选为本机，并关闭「自动发送」。默认优先用原来的 Android 系统语音；断网或服务中断时，已识别的文字会保留，手机用内置的 Paraformer 听接下来的话。想从第一个字就不上网，打开「仅用离线普通话」；不必下载模型或填写密钥。如果选的是云服务，网络失败时会用刚才同一段录音在本机补转。

数字会在发送前显示在输入框里：“一百二十”显示为 `120`，“编号是零零七”保留为 `007`，“九乘十九”显示为 `9 × 19`。号码、金额等重要数字可以先核对或修改再发送。

离线听写和联网聊天是两件事：断网时可以把话转成文字，所选聊天模型如果在云端，发送后仍需要网络才能回答。若识别中断，已识别的文字会留在输入框，可以先改字再继续。

## 如果只想被提醒

在「设置 → 跨应用助手 → 手机事件提醒」选择应用与事件，例如“某个应用发来通知”。通知类规则需要你另外开启系统通知使用权。匹配后手机会提醒你；即便关联了已有任务，也要你确认才会运行。关闭规则不影响普通聊天。

## 遇到提示怎么处理

- **清理内存后侧边白线不见了：**打开 AndroidHarness。如果看到「重新连接」，点它进入系统的数字助理设置；若仍勾着 AndroidHarness，先选「无」，再选回 AndroidHarness。也可以从「设置 → 跨应用助手」进入。只需恢复系统助理连接，不用清除数据或重配模型。这条常驻白线和任务进行时的顶部小胶囊是两个不同的提示。
- **找不到目标应用：**在系统数字助理设置中允许提供屏幕上的文字，回到目标应用重试。
- **屏幕变了或没有看到按钮：**先停在目标页，让助手重新观察。锁屏、权限弹窗、分屏或敏感输入页面请先自己处理。
- **点了一次，还没看到结果：**助手会重新看当前画面，按新画面决定下一步。连续点按、拖动不要求换页，也不要求画面上有文字。发送、付款等提交则要核对结果：如果无法确认上一笔是否生效，助手不会自动再提交一遍。
- **模型看不了图片：**仍可通过页面上的控件工作；截图可用时，可让助手在本机识别中英文文字。需要按像素点选、但模型没收到图片时，助手不会猜坐标。
